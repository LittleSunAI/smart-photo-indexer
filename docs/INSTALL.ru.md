# Установка Smart Photo Indexer 1.0.6

1. Запустите SmartPhoto-Setup-1.0.6-x64.exe в Windows 10/11 x64. Установщик включает установщик Microsoft WebView2. Для обычной работы Node.js, Rust и исходники не нужны.
2. Перед обновлением закройте Smart Photo обычным способом. Обновление заменяет файлы программы; отдельно сохраняйте резервные копии ценных фотографий и данных приложения.
3. Откройте папку. Просмотр работает без ключа AI. Для локального распознавания нужно явно подготовить модель; облачные операции требуют собственного ключа сервиса и могут быть платными.
4. В настройках доступны русский, английский, немецкий и французский. Кнопка ? открывает обучение и справочник отдельно в каждом окне.

Для открытия из Windows выберите «Открыть с помощью → Smart Photo Indexer». Программа регистрируется как доступный просмотрщик, не заменяя автоматически все назначения файлов. Приложение по умолчанию выбирается в настройках Windows.

Контрольная сумма находится в SHA256SUMS.txt; сравните её через Get-FileHash -Algorithm SHA256. Цифровой подписи пока нет, Windows может показать предупреждение об издателе/репутации. Удаление — через список установленных приложений Windows. Модели, ключи и личная фотобиблиотека в этот комплект не входят.

Для нового профиля при выборе «Локально» используется «Быстрая · Qwen3-VL 2B», загрузка около 1,93 ГБ. Нажмите «Установить» и подтвердите подготовку: приложение скачает Ollama и модель. Сохранённый ранее выбор модели остаётся прежним. Подробные Qwen3.5 требуют больше времени; быстрый режим создаёт краткое описание и теги.

В версии 1.0.2 новые задания Qwen3.5 2B и 4B создают подробное описание и теги без отдельного этапа рассуждений. Включать или отключать этот режим вручную не нужно. Скорость зависит от компьютера и размера снимка; результат стоит проверить на неточности.
