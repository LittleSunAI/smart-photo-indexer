The source repository and automatically generated Source code archives are separate from the installer. Models and service keys are not bundled. Microsoft WebView2 and third-party license notices are included in the installer. The installer is unsigned.

Paid model requests, physical multi-monitor/DPI behavior and unavailable real local inference are not repeated here.
