# Documentation media

The two photos in demo/ and cover-art.png were generated for this project with the built-in image generation tool. Exact prompts and hashes are in generated-sources.json. They do not depict a user photo library and are not third-party stock photographs.

cover.png combines the decorative artwork with crisp typographic layout. The four numbered cards are code-rendered workflow illustrations, clearly labeled as such. Re-render them with node scripts/render-public-media.mjs on a Windows machine with Microsoft Edge and npm dependencies installed. The images contain common English copy; every README provides translated captions and explanatory text.

The three screenshot-*.png files are real captures of the prepared Smart Photo Indexer builds. The library view was updated for1.0.0; the unchanged editor and viewer views retain their0.38.7 capture versions, recorded per file in captures.json. They use only the generated demo photos. Example descriptions and tags are entered manually; no AI recognition accuracy or paid editing result is being claimed. A source/build hash and capture record are provided in the preparation audit.
