**Фотобиблиотека, в которой можно искать словами.** Программа для Windows от **LittleSunAI**: просмотр фотографий, создание описаний и тегов, поиск по сохранённым данным и редактирование снимков.

**1.0.6 · Windows 10/11 x64 · RU / EN / DE / FR**

> Открытая программа от **LittleSunAI** под [Apache License 2.0](LICENSE). [Авторское уведомление](NOTICE) · [Подробнее о лицензии](docs/LICENSING_STATUS.md).

OpenRouter временно отключён до завершения проверки. Fal AI и локальные модели доступны; сохранённые настройки и ключи OpenRouter остаются на месте.

## Что можно делать

- Просматривать папки карточками, списком или таблицей, пользоваться избранным и коллекциями.
- Получать описания, теги или оба результата: через локальную модель Ollama либо отдельно настроенный облачный сервис.
- Искать по сохранённым описаниям, тегам, именам и путям — в текущей папке или всей индексированной библиотеке. Это текстовый поиск; векторный поиск по сходству не заявляется.
- Готовить очереди обработки, следить за ходом работы, ошибками и доступным повтором.
- Открывать отдельный просмотрщик с масштабом, перемещением и слайд-шоу; переходить в редактор для локальной обрезки, изменения размера и поддерживаемых облачных правок.
- Работать с пакетными тегами, XMP, экспортом данных и проектами редактора. Ответы AI нужно проверять.
- Видеть дерево вариантов правки, сравнивать кадры и продолжать от выбранного. Сохранять историю проекта отдельно от изображения; очищать промежуточные файлы через предварительную проверку.

## Установка и начало работы

Готовый установщик для Windows скачивайте в [Releases](https://github.com/LittleSunAI/smart-photo-indexer/releases/latest): `SmartPhoto-Setup-1.0.6-x64.exe`. Исходники находятся в этом репозитории и в архивах Source code. Инструкции и SHA256SUMS.txt приложены к релизу отдельно.

1. Установите программу для Windows x64. Для обычной работы Node.js и Rust не нужны.
2. Выберите папку. Просмотр работает без ключа и AI-модели.
3. Для распознавания явно подготовьте локальную модель либо укажите собственный облачный ключ. Облачные операции могут быть платными.
4. Выберите результат: описание, теги или всё вместе. Проверяйте сгенерированную информацию.
5. Язык меняется в настройках. Кнопка **?** открывает обучение и справочник отдельно в каждом окне.

[Установка подробнее](docs/INSTALL.ru.md) · [Данные и сервисы](docs/DATA_AND_SERVICES.md)

## Сборка, проверки и ограничения

Требования и сборка — в [BUILD.md](docs/BUILD.md). Обычный переносимый набор проверок не читает сохранённые ключи пользователя, не скачивает модели и не обращается к платным API.

```powershell
npm ci
npm run verify:structure
npm test
npm run build
```

Установщик пока без цифровой подписи. Ключи и модели в комплект не входят. Скорость и память локальной модели зависят от компьютера; доступность облака, списания и размеры AI-результата — от сервиса. Не каждая модель правки принимает маску и дополнительные картинки. Перед явными операциями изменения файлов сохраняйте резервные копии важных оригиналов.
