# Contributions

The original project code is licensed under Apache License 2.0; see [LICENSE](LICENSE) and [NOTICE](NOTICE). Unless explicitly stated otherwise, contributions intentionally submitted for inclusion are provided under the same license, as described in section 5. Preserve third-party notices.

For a bug report, include the app version, Windows version, a short sequence of actions and the expected result. Prefer generated or freely shareable sample photos. Do not attach keys, personal databases or private images. See [SECURITY.md](SECURITY.md) for sensitive reports.

Build and test instructions are in [docs/BUILD.md](docs/BUILD.md). Keep changes focused. Check the behavior changed and its immediate consumers; use screenshots for visual changes. Do not put paid requests, access to a real user profile or model downloads into the default test suite.

Interface strings live in the four author locale directories. Preserve wire IDs, user text, filenames, prompts and model request contracts when changing UI copy. The vendored Tao patch and its upstream license notices must remain documented.
