# Авторские тексты интерфейса

Редактировать JSON в ru/en/de/fr, затем `npm run help:compile`.
Проверка без записи: `node scripts/compile-help-catalog.mjs --check`.
Generated runtime/types находятся рядом в ../generated и ../help, вручную их не редактировать.

Help хранит прежние стабильные ID и именованные аргументы. Tour хранит собственные заголовки/абзацы; у reuse-карточек только bodyRef на help вместо повторного тела. Аргументы обычной авторской строки записываются как {name}, rich-текст использует прежние **выделения**, `клавиши` и абзацы. Compiler преобразует эти форматы отдельно.

Материалы docs/training-localization/translations и docs/ui-help/texts после переноса — исторические снимки подготовки. Не исправлять их параллельно с этим источником и не запускать первоначальный перевод поверх вычитанных JSON. Legacy-tour сохранён для происхождения текста, новые маршруты используют tour.


RU — язык по умолчанию, EN/DE/FR выбираются в настройках. LocaleController до React читает прежние UiPreferencesv1, загружает выбранный локальный chunk и синхронизирует окна. Русский ресурс загружается сразу; дополнительные языки — по необходимости.

Подписи получать при отображении: через messages()/text()/nativeDisplayText(), с useCurrentLocale() у владельца React. Не сохранять локализованный текст вместо enum/статуса/составляющих пользовательских данных. Для ошибок редактора хранить technicalError(), для отсутствующей даты — отсутствие значения; переводить при render. Имена файлов, metadata, промпты, ответы AI, technical/raw и протокольные IDs не переводятся.

После правки — compile/check и адресный сценарий соответствующего владельца. Итоговые source/mock/installed проверки этой миграции описаны в STEP/VERIFICATION_PLAN (CHECK-64–70), фактические результаты — в CHECK_REPORT.md.
